# R6 StratShare

Strats für Rainbow Six Siege erstellen, anschauen und mit Freunden teilen – lokal auf deinem PC.

**Für Windows 10/11 (64 Bit).** Keine Installation von Node.js oder Docker und keine Internetverbindung erforderlich. Ein aktueller Browser genügt.

## 🚀 Starten

1. Rechtsklick auf `R6-StratShare-Windows.zip` → **Alle extrahieren…**
2. Den entpackten Ordner öffnen und **`START.cmd`** doppelklicken.
3. R6 StratShare öffnet sich automatisch im Browser.

> **Wichtig:** Die gesamte ZIP entpacken und das Konsolenfenster während der Nutzung geöffnet lassen.

## ✏️ Strats erstellen und speichern

Unter **Strat Editor** Karte und Seite auswählen und **Start Editor** anklicken. Anschließend könnt ihr Spieler, Operatoren, Markierungen, Zeichnungen und weitere Details festlegen.

- **Save** speichert die Strat als JSON-Datei auf eurem PC.
- **Copy** kopiert den JSON-Text in die Zwischenablage.

> **Vor dem Beenden speichern!** Die lokale Version bietet keine Account- oder Cloud-Speicherung.

## 👀 Strats anschauen und teilen

1. Eine gespeicherte JSON-Datei mit einem Texteditor öffnen, z. B. Windows Editor (Notepad).
2. Mit **Strg+A** alles markieren und mit **Strg+C** kopieren.
3. Unter **View Strat** den Text mit **Strg+V** in **Paste strat JSON** einfügen.
4. **Load Strat** anklicken.

Nach **Copy** könnt ihr den Text direkt im Viewer einfügen.

Zum Teilen einfach die **JSON-Datei verschicken**. Zum Weiterbearbeiten im **Strat Editor** auf **Load JSON** klicken und den JSON-Text einfügen.

## ⏹️ Beenden

Die Strat mit **Save** sichern und anschließend im Konsolenfenster **Strg+C** drücken.

Das Schließen des Browser-Tabs beendet den lokalen Server noch nicht. Beim nächsten Mal startet ihr die Anwendung wieder über `START.cmd`.

## 🔧 Hilfe

| Problem | Lösung |
| --- | --- |
| Der Browser öffnet sich nicht. | Die Adresse aus dem Konsolenfenster im Browser öffnen, z. B. `http://127.0.0.1:3766`. Die Portnummer kann abweichen. |
| Die Startdatei oder andere Dateien fehlen. | Die gesamte ZIP erneut in einen neuen Ordner entpacken. Alle Unterordner gehören zum Programm. |
| Beim Start erscheint ein Fehler. | Die Fehlermeldung kopieren oder fotografieren und an den Absender des Pakets schicken. |
